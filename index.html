3. Mapeo RGB → Sonido

🔴 ROJO (R) → ALTURA

El rojo determina la frecuencia.

R = 0 → grave
R = 255 → agudo

🟢 VERDE (G) → FILTRO

El verde controla la frecuencia de corte del filtro.

G = 0 → filtro cerrado
G = 255 → sonido brillante

🔵 AZUL (B) → TECLADO

El azul selecciona diferentes notas del teclado.

B = 0 → nota grave
B = 255 → nota aguda

5. ¿Cómo funciona?

La imagen se divide en pequeños bloques de píxeles. Se obtiene el promedio RGB de cada bloque y ese valor se transforma en sonido.

🔴 ROJO
Controla la frecuencia principal. Más rojo = sonido más agudo.
🟢 VERDE
Controla el filtro pasa-bajos. Más verde = sonido más brillante.
🔵 AZUL
Selecciona la nota del teclado. Más azul = nota más alta.
